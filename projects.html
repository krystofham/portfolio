Projekt — 06

ERS Boost Zone Estimator

Python FastF1 Telemetrie Fyzikální model Datová analýza 2026 F1

F1 API pro rok 2026 neodhaluje binární příznaky ERS módů — Straight Line Mode a Overtake Mode. Tento nástroj je odhaduje fyzikálním silovým modelem přímo z veřejné telemetrie přes FastF1. Vznikl jako odpověď na issue #864 v oficiálním repozitáři FastF1.

  • Silový model F = m·a + F_aero − F_ICE_baseline s Savitzky-Golay smoothingem
  • Duální detekce zón — SLM (65. percentil) a OTM (88. percentil)
